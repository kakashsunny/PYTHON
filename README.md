## 📖 About

This repository is my personal collection of **Python notes**, built while learning the language from the ground up. It's organized as a progressive path — start at the basics, and work your way up to advanced topics like decorators, generators, and OOP design patterns.

Whether you're a beginner or brushing up on advanced concepts, feel free to explore, fork, or contribute.

---

## 🚀 Getting Started

### Prerequisites
- Python 3.10 or higher installed → [Download here](https://www.python.org/downloads/)
- A code editor (VS Code recommended)
- Basic familiarity with the command line

### Clone the repository

```bash
git clone https://github.com/sunny/python-notes.git
cd python-notes
```

### Run any note/script

```bash
python basics/01_variables.py
```
